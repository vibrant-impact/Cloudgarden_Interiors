# Cloudgarden Interiors | Biophilic Web Design Study

A responsive, hand-coded web project showcasing the intersection of biophilic design principles and advanced CSS layout techniques. 

## 🌐 [View Live Project]([https://vibrant-impact.github.io/Cloudgarden_Interiors/](https://cloudgarden-interiors.vercel.app/))

---

## 📐 The Technical Challenge
This project was developed as a rigorous study in **two-dimensional layout logic**. While modern frameworks often rely on Flexbox for simplicity, this site was architected strictly using **CSS Grid** to demonstrate mastery over complex alignment and structural integrity.

### Key Technical Achievements:
* **Grid-Exclusive Architecture:** The entire site—including the navigation, hero section, and gallery—is built using CSS Grid to maintain a precise editorial feel.
* **Responsive Fluidity:** Implemented a mobile-first approach, ensuring that the biophilic aesthetic remains intact across mobile, tablet, and desktop breakpoints.
* **Semantic HTML5:** Prioritized accessibility and SEO by using clean, semantic tags to define the document structure.

---

## 🌿 Design Philosophy
**Cloudgarden Interiors** represents a "Modern and Minimalist" approach to indoor-outdoor living. 

* **Aesthetic:** Luxurious and Indulgent.
* **Color Palette:** Earthy tones paired with high-contrast whitespace to emphasize natural light and organic textures.
* **Typography:** Selected for high legibility and a sophisticated, architectural vibe.
